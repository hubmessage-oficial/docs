## Overview

Sends a message with action buttons to a contact. The `content.type` field must be `INTERACTIVE_ACTION`.

Available button types:

- **URL** — Opens a link when clicked
- **CALL** — Calls a number when clicked

The `header` and `footer` fields are optional.

<Warning>
  The **CALL** button has not been implemented on any channel yet. The type is
  accepted by the request and the API responds `200`, but the button never
  reaches the recipient. Use **URL** instead, and put the phone number in the
  message body if you need it.
</Warning>
