## Overview

After [creating a channel](/en/channels/create-channel) of type `BOT_TELEGRAM`, connect a Telegram bot to send and receive messages.

Telegram does not use OAuth for this flow. The connection uses the token generated by **BotFather**.

## Connect through the Dashboard

Open the [Dashboard]({frontendUrl}), select the Telegram channel, and follow the activation flow. When the Dashboard asks for the token, enter the value provided by BotFather.

## Connect via API

### 1. Create the bot with BotFather

In Telegram, open a conversation with **BotFather**, send `/newbot`, and follow the instructions. BotFather will provide a token similar to:

```text
123456789:AAExampleBotToken
```

Store this token as a secret. It allows control of the bot.

### 2. Activate the channel

Send the token to:

`POST /v1/channels/{channelId}/activate-telegram`

Use the **Secret Key** in the header:

```bash
curl -X POST https://api.hubmessage.io/v1/channels/CHANNEL_ID/activate-telegram \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_SECRET_KEY" \
  -d '{
    "token": "123456789:AAExampleBotToken"
  }'
```

Hub Message validates the token with Telegram. If it is valid, the channel is activated and the bot webhook is configured automatically.

A successful activation returns:

```json
{
  "externalId": "123456789",
  "connected": true,
  "displayName": "My Bot (@my_bot)"
}
```

<Warning>
  Never expose the BotFather token in the frontend or in logs. Make the activation call from your backend using the Secret Key.
</Warning>

## Disconnect the channel

To deactivate the bot and remove its configured webhook, use:

`POST /v1/channels/{channelId}/deactivate-telegram`

```bash
curl -X POST https://api.hubmessage.io/v1/channels/CHANNEL_ID/deactivate-telegram \
  -H "Authorization: Bearer YOUR_SECRET_KEY"
```

After deactivation, the channel stops receiving bot events. To connect it again, send the token again.

## Next steps

With the channel connected, use the `channelId` to send [free messages](/en/messages/introduction). To reply to a conversation, use the chat identifier received in the [webhook](/en/webhooks/payloads).
