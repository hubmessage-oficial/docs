## Visão geral

Para utilizar a **API Oficial do WhatsApp**, você precisa primeiro criar um **Portfólio Empresarial** no Meta Business Manager. Este guia mostra o passo a passo completo.

## Passo 1: Acesse o site

Acesse o link para acessar o site: [business.facebook.com](https://business.facebook.com/)

Após acessar o site, clique para criar um portfólio empresarial, conforme imagem abaixo:

<Frame>
  <img src="/images/como-criar.png" alt="Criar portfólio empresarial" />
</Frame>

## Passo 2: Preencher informações

Após clicar para criar um portfólio empresarial, você deverá preencher as seguintes informações:

- **Nome do portfólio empresarial**: deve inserir o nome da sua empresa ou marca
- **Nome e sobrenome**: deve inserir o nome e sobrenome do responsável pela conta
- **E-mail comercial**: deve inserir o e-mail que você utilizará para gerenciar seu portfólio empresarial. É importante que seja um e-mail profissional ou da sua empresa.

## Passo 3: Criar o portfólio empresarial

Após preencher as informações, clique no botão **"Criar"**.

<Frame>
  <img src="/images/como-criar-2.png" alt="Botão criar portfólio" />
</Frame>

Após isso, o portfólio empresarial será criado!

<Frame>
  <img src="/images/como-criar-3.png" alt="Portfólio empresarial criado" />
</Frame>

<Note>
  Com o portfólio criado, o próximo passo é [verificar seu portfólio](/whatsapp-official/portfolio/verify-portfolio) para liberar todas as funcionalidades da API Oficial.
</Note>
