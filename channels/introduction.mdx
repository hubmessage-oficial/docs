## O que é um canal?

No {projectName}, um **canal** representa uma conexão com o WhatsApp via API Oficial da Meta.

Cada canal é vinculado a um número de telefone do WhatsApp Business. Por exemplo, ao conectar o número `+55 11 99999-9999`, isso cria um canal com `channelId` único usado em todas as chamadas de API.

O `channelId` é o identificador único do canal e é usado em todas as chamadas de API para enviar [mensagens livres](/messages/introduction), [templates](/messages/send-template), webhooks, etc.

## Plataforma suportada

| Plataforma | Tipo | Status |
|---|---|---|
| **WhatsApp** (API Oficial Meta) | `META_WHATSAPP` | Disponível |

## Fluxo para começar

<Steps>
  <Step title="Gere suas credenciais">
    Se ainda não fez, gere sua **Public Key** e **Secret Key** em [Autenticação](/authentication).
  </Step>
  <Step title="Crie o canal">
    Crie um novo canal pelo [Dashboard]({frontendUrl}) ou via API usando o endpoint [Criar canal](/channels/create-channel).
  </Step>
  <Step title="Conecte o canal">
    Use o [fluxo de conexão via SDK + API](/channels/connect-channel), que integra com a autenticação oficial da Meta.
  </Step>
  <Step title="Ative a assinatura (contas ENTERPRISE)">
    Parceiros e revendedores com role ENTERPRISE devem ativar a assinatura do canal via [Assinar canal](/channels/subscribe-channel) antes de começar a usar.
  </Step>
  <Step title="Envie mensagens">
    Com o canal conectado, use o `channelId` para enviar [mensagens livres](/messages/introduction) (dentro da janela de 24h) ou [templates](/messages/send-template) (fora da janela).
  </Step>
</Steps>
